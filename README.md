# Student Management System

## About the Project
The Student Management System is a web-based application developed using Python Flask and PostgreSQL. It helps administrators manage student records efficiently through a simple interface.

## Features
- Admin Login and Authentication
- Add New Students
- View Student Records
- Edit Student Details
- Delete Student Records
- PostgreSQL Database Integration
- Secure Password Hashing
- Logout and Dashboard Protection

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** PostgreSQL
- **Deployment:** Render
- **Version Control:** Git and GitHub

## Installation and Setup

1. Clone the repository:

   `git clone https://github.com/kubendranl/StudentManagementSystem.git`

2. Open the project folder:

   `cd StudentManagementSystem`

3. Create a virtual environment:

   `python -m venv .venv`

4. Activate it:

   `.\.venv\Scripts\Activate`

5. Install dependencies:

   `pip install -r requirements.txt`

6. Configure your environment variables in a local `.env` file.

7. Run the application:

   `python app.py`

8. Open your browser:

   `http://127.0.0.1:5000`
